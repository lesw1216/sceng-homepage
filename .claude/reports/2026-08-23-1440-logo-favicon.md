# 1차 시안 수정 — 로고·파비콘 추가 요구사항 반영

## 작업 요청 요약

`.claude/docs/requirements/first-draft/README.md` 기준으로 추가·수정된 요구사항 반영.
직전 작업(11 커밋) 이후 변경된 요구사항은 2건.

- `00-global.md` §2.3: `/public/sce-symbol.svg`를 파비콘으로 사용
- `01-header.md`: 헤더 로고를 `/public/sce-logo-ko.svg`로 교체, 비율 유지한 채 헤더 하단 테두리와 2px 간격이 되도록 확대
- `README.md`: 브랜치가 `refactor/detail-first`면 유지 (기존 브랜치 그대로 작업)

## 사전 계획

1. 로고 SVG의 실제 bounding box를 확인해 확대 시 필요한 가로 폭 산출
2. 헤더 로고를 높이 기준(`헤더 높이 - 4px`) 렌더로 변경, 폭은 `w-auto`
3. 확대에 따른 헤더 가로 공간 부족 구간 확인 후 nav 노출 기준 조정
4. `metadata.icons`로 파비콘 지정 + Next 기본 `favicon.ico` 제거
5. 요구사항 문서 단위로 커밋(00-global / 01-header)

## 결정 사항

| 항목 | 결정 | 근거 |
|------|------|------|
| 로고 크기 기준 | 헤더 높이 − 4px (상·하 2px) | 세로 중앙 정렬 상태에서 하단 BrandLine과 2px 간격 |
| 태블릿 nav | 데스크톱 nav 노출 기준 `md`(768) → `lg`(1024) | 로고 비율 5.6:1 → 헤더 높이 80px 기준 폭 약 425px. 768px 구간에서 nav(약 440px)와 합쳐 컨테이너(720px) 초과 → 사용자 확인 후 상향 |
| 헤더 높이 | `h-14 sm:h-20 xl:h-24` | 로고 폭이 높이에 비례하므로 모바일(≤640px)·1024px 구간 오버플로 방지 |
| SVG 렌더 | `next/image` + `unoptimized` | `dangerouslyAllowSVG` 미설정 상태에서 `/_next/image`가 SVG를 400으로 거부(실측 확인). SVG는 최적화 이득도 없음 |
| 파비콘 | `metadata.icons` + 기본 `favicon.ico` 삭제 | 파일 컨벤션(`app/favicon.ico`)이 남아 있으면 Next 기본 아이콘 링크가 함께 출력됨 |
| 푸터 로고 | 동일 SVG로 통일, `logo-sce.jpg` 삭제 | 요구사항 외 항목이나, 헤더만 교체하면 동일 로고가 래스터/벡터로 이원화됨 |

## 알려진 제약 / follow-up

- `/favicon.ico`는 이제 404. 선언된 SVG 아이콘으로 최신 브라우저는 정상 동작하나, 레거시 폴백이 필요하면 `sce-symbol.svg`를 32×32 ICO로 변환해 `src/app/favicon.ico`로 추가해야 한다(현재 환경에 변환 도구 없음).
- `sce-symbol.svg`의 viewBox는 500×218(비정사각) → 파비콘에서 상하 여백이 생긴다. 정사각 크롭 버전이 있으면 교체 권장.
- 태블릿(768~1023px)은 이제 햄버거 메뉴를 사용한다. 데스크톱 nav를 이 구간에도 노출하려면 로고를 축소해야 한다.
- 요구사항 문서의 파일명 표기 `sce-log-ko.svg`는 실제 파일명 `sce-logo-ko.svg`와 다름(문서 오타로 판단, 실제 파일 기준 적용).
- 브라우저 실측(로고 하단 2px 간격)은 미수행 — 계산상 값이며 시각 확인 필요.
