# 6. 실적 현황 요구사항

> 이하 `실적 현황` 요구사항에서 각 실적은 `프로젝트` 또는 `실적`이라고 지칭한다.

> 실적을 Grid 형태로 보여주는 목록은 `실적 리스트` 또는 `리스트`라고 지칭한다.

실적 현황에서는 다음 기능을 제공한다.

    검색
    사업 분야 필터
    연도 필터

- 검색과 두 종류의 필터는 동시에 적용할 수 있다.

- 선택된 모든 조건을 만족하는 프로젝트만 표시한다.

사업 분야 예시:

```
전체
산업 자동화
빌딩 자동화
데이터 센터 자동화
```

---

## 6.1 검색 및 필터 전체 배치

검색과 필터는 동일한 한 줄에 배치한다.

순서는 다음과 같다.

```
사업 분야 - 연도 - 검색
```

- 사업 분야와 연도는 하나의 필터 Group으로 구성한다.
- 검색은 별도의 단일 Block으로 구성한다.

Desktop에서는 다음과 같은 형태로 양끝에 배치한다.

```
왼쪽 → 사업 분야 + 연도
오른쪽 → 검색
```

- 두 Block은 전체 Filter Container 안에서 **양쪽 끝으로 분리되어 보이도록 배치**한다.
- 기존 요구사항의 `around-space` 형태를 유지하되 각 영역이 시각적으로 명확하게 구분되어야 한다.

---

## 6.2 검색

검색 Bar를 추가한다.

구성:

- Text Input
- Input 오른쪽의 돋보기 아이콘

검색 실행 조건:

- Enter 입력
- 돋보기 아이콘 클릭

둘 중 어느 방법을 사용해도 동일한 검색 로직이 실행되어야 한다.

실시간 입력마다 검색되는 방식이 아니라 **명시적으로 검색을 실행하는 방식**으로 구성한다.

이는 추후 Backend Server 도입 시 검색 API 요청 방식으로 변경할 수 있도록 고려한다.

Placeholder에는 다음 항목으로 검색할 수 있다는 점을 안내한다.

- 프로젝트 이름
- 고객사
- 발주처
- 위치

예:

`프로젝트 이름, 고객사, 발주처, 위치를 입력하세요.`

검색어가 없는 상태에서 검색을 실행한 경우 전체 데이터가 표시되도록 한다.

---

## 6.3 사업 분야 필터

사업 분야 필터는 Select Dropdown을 사용하지 않는다.

모든 사업 분야 선택지를 화면에 직접 노출하는 **단일 선택형 Filter Button Group**으로 구현한다.

기본 선택값:

`전체`

동작:

- 한 번에 하나의 사업 분야만 선택 가능
- 다른 사업 분야를 선택하면 기존 선택은 해제
- 선택된 사업 분야에 해당하는 프로젝트만 표시

상태별 글자 색상:

- 선택됨 → 네이비
- 선택되지 않음 → 회색

현재 선택된 항목은 글자 색상뿐만 아니라 필요할 경우 Font Weight 등 최소한의 디자인 차이를 이용하여 **현재 선택값을 명확히 인식할 수 있도록 한다.**

단, 전역 요구사항에 따라 필터 배경 전체를 네이비 또는 오렌지로 변경하지 않는다.

---

## 6.4 연도 필터

연도는 **Select Dropdown** 방식으로 구현한다.

기본 선택값:

`전체 연도`

`전체 연도`를 선택하면 모든 연도의 프로젝트를 표시한다.

특정 연도를 선택하면 해당 연도에 수행된 프로젝트만 표시한다.

연도 선택지는 최신 연도부터 과거 연도 순으로 내림차순 배치한다.

향후 Backend Server 및 실제 데이터 연동을 고려하여 프로젝트 데이터에 존재하는 연도를 기준으로 Dropdown Item을 구성할 수 있는 구조를 고려한다.

---

## 6.5 검색과 필터 조합

다음 세 조건은 **AND 조건**으로 결합한다.

- 검색어
- 사업 분야
- 연도

예:

사업 분야 = `산업 자동화`  
연도 = `2026`  
검색 = `A 고객사`

라면 세 조건을 모두 만족하는 프로젝트만 표시한다.

각 조건에서 `전체`, `전체 연도`, 빈 검색어는 해당 조건을 제한하지 않는 것으로 처리한다.

---

## 6.6 프로젝트 정렬

프로젝트는 **프로젝트 시작일 기준 최신 프로젝트가 먼저 표시되는 내림차순 정렬**을 기본으로 한다.

정렬 우선순위는 다음과 같다.

### 1순위

프로젝트 시작일 내림차순

### 2순위

프로젝트 시작일이 동일한 경우 프로젝트 종료일이 더 늦은 프로젝트를 먼저 표시한다.

예:

- A 프로젝트 종료일 → 2026.08
- B 프로젝트 종료일 → 2026.06

A 프로젝트를 먼저 표시한다.

### 3순위

프로젝트 시작일과 종료일이 모두 동일하면 **실적 등록 순서를 기준으로 내림차순 정렬**한다.

향후 Backend Server 도입 시 해당 정렬은 Backend에서 처리할 수 있도록 고려한다.

---

## 6.7 실적 리스트

실적 리스트는 Desktop 기준:

- **5열**
- **2행**

Grid 형태로 구성한다.

따라서 한 페이지에서 최대 **10개의 프로젝트**를 표시한다.

프로젝트 수가 10개를 초과하면 다음 페이지로 넘긴다.

---

## 6.8 프로젝트 카드 내용

각 프로젝트 Item에는 다음 정보를 표시한다.

- 프로젝트 대표 사진
- 프로젝트 이름
- 고객
- 발주처
- 프로젝트 기간
- 위치

각 Item의 정보 배치 순서 및 Typography는 모든 카드에서 동일해야 한다.

프로젝트 카드는 클릭 가능해야 한다.

프로젝트를 클릭하면 해당 프로젝트의 **실적 상세 화면으로 이동한다.**

카드의 디자인은 다음과 같이 수정한다.

- border: 1px solid 회색
- shadow는 제일 작은 값
- border-redius: sm

hover 시 살짝 카드가 띄워지는 모션을 구성한다.

카드의 Item 글씨 색상은 다음과 같이 수정한다.

- 카드 Item 글씨: **네이비**
- 카드 Item의 내용의 글씨 색상은 유지한다.

---

## 6.9 페이지네이션

실적 리스트 아래에 Pagination을 추가한다.

페이지가 2개 이상인 경우 리스트의 좌우에 다음 이동 버튼을 표시한다.

- `<`
- `>`

동작:

- `<` → 이전 페이지
- `>` → 다음 페이지

첫 번째 페이지:

- 왼쪽 `<` 버튼은 표시하지 않는다.

마지막 페이지:

- 오른쪽 `>` 버튼은 표시하지 않는다.

`<`, `>`를 이용하여 페이지를 변경한 경우 리스트 하단의 Pagination에서도 현재 페이지 번호가 즉시 Active 상태로 변경되어야 한다.

리스트 하단 Pagination에는:

- 페이지 번호
- 맨 앞 페이지 이동 버튼
- 맨 뒤 페이지 이동 버튼

을 제공한다.

현재 Active 페이지는 다른 페이지 번호와 명확하게 구분한다.

Pagination에 포함된 모든 클릭 가능 요소에는 전역 요구사항의 Pointer Cursor 규칙을 적용한다.

현재 `<`, `>` 위치는 1행의 중간이다. 위치를 다음같이 수정한다.

- 한 페이지에 2행이라면 2행의 중간위치로 위치시킨다.
- 한 페이지에 1행이라면 1행의 중간 위치로 위치시킨다.

`<`,`>` 위치를 리스트 컨테이너의 내부가 아닌 밖에 위치시킨다.
이유는 현재 필터 섹션와 좌우 길이가 맞지 않는다.

`<`,`>`의 디자인은 배경없이 테두리 선 없이 `<`,`>`만 표시한다.

## 6.10 데모 데이터

현재 실제 실적 데이터가 존재하지 않으므로 리스트 디자인과 필터, 검색 및 Pagination 기능을 테스트할 수 있는 Demo Data를 생성한다.

현재 정의된 **3개의 사업 영역별로 각각 10개**, 총 30개의 Demo Project를 생성한다.

각 Demo Data에는 최소 다음 값이 포함되어야 한다.

- 프로젝트 대표 이미지
- 프로젝트 이름
- 사업 분야
- 고객
- 발주처
- 프로젝트 시작일
- 프로젝트 종료일
- 위치
- 등록 순서를 구분할 수 있는 값

이미지는 각 사업 영역과 연관된 **저작권 문제가 없는 이미지**를 사용하여 임시 대표 이미지로 대체한다.

이는 디자인 및 기능 테스트를 위한 Demo Data이다.

---

## 6.11 실적 없음 상태

실적 데이터가 존재하지 않는 상태를 테스트할 수 있도록 Empty State UI를 함께 구현한다.

다음 두 경우의 안내 문구는 서로 달라야 한다.

### A. 홈페이지 개설 초기

아직 등록된 실적 자체가 하나도 없는 경우.

### B. 특정 조건의 실적 없음

전체적으로는 실적이 존재하지만:

- 특정 연도
- 특정 사업 분야
- 검색 결과
- 또는 이 조건들의 조합

에서 일치하는 프로젝트가 없는 경우.

두 상태가 사용자 입장에서 구분될 수 있도록 서로 다른 안내 문구를 사용한다.

현재 실적이 없는 경우 표시되는 안내 영역의 배경이 네이비로 구성되어 있으나 **네이비 배경을 제거한다.**

배경 제거에 맞춰 안내 글자의 색상도 흰색이 아닌 가독성이 확보되는 적절한 텍스트 색상으로 변경한다.

전역 배경색 요구사항을 따른다.

**위 6.11 요구사항을 이전 작업에서 수행하지 않았음. 필히 작업 바람!!**

## 6.12 검색바 디자인

입력을 위해 커서를 입력창에 클릭했을 때 오렌지 테두리가 나오는 애니메이션을 다음과 같이 수정한다.

- 입력창 하단에 `회사 대표 선` Underline이 나타난다.
- Underline은 **왼쪽에서 오른쪽으로 길이가 증가하는 Animation**으로 표시한다.
- 외부 화면을 클릭하여 포커스가 사라지면 반대 방향으로 자연스럽게 사라지도록 한다.

- 포커스 시 검색 아이콘의 색상은 **네이비**로 수정한다.
