# 8. 사업 영역 요구사항

> 이하 `사업 영역` 요구사항에서 2열로 구성된 **사업 이미지 + 사업 설명 영역 전체를 `본문`이라고 지칭한다.**

## 8.1 기본 간격

사업 영역 제목 아래에는 다음 요소가 순서대로 존재한다.

1. 안내 문구
2. 사업 영역 종류 탭
3. 본문

안내 문구 → 사업 영역 종류 탭 → 본문 사이의 Vertical Gap은 임의로 서로 다르게 설정하지 않는다.

**사업 영역 종류 탭과 본문 사이의 현재 간격을 기준값으로 사용하여 1, 2, 3의 간격을 통일한다.**

---

## 8.2 본문

- 본문 2열 영역 내부에 존재하는 별도의 수평선은 제거한다.

---

## 8.3 본문 위치

본문은 다음 구조를 유지한다.

- 1열 → 사업 영역 이미지
- 2열 → 사업 영역 설명

---

- 2열 설명 내용의 시작 위치를 **1열 이미지의 상단 위치와 동일한 수평선상에 맞춘다.**
- 모든 사업 영역 탭에서 2열 설명의 시작 위치는 동일해야 한다.
- 탭을 변경했을 때 콘텐츠 길이 차이로 인해 설명 시작 위치가 위아래로 변경되어서는 안 된다.

---

## 8.4 본문 줄바꿈

본문 2열의 내용은 문장이 길어져도 **임의로 줄바꿈하지 않는다.**

Desktop에서는 가능한 한 한 줄 표시를 유지한다.

단, 반응형 화면에서 콘텐츠가 화면 밖으로 넘치거나 레이아웃이 깨지는 상황이 발생하는 경우에는 별도의 모바일 반응형 처리를 적용하되:

- 문구를 임의로 삭제하지 않는다.
- 문구를 축약하지 않는다.
- Desktop 디자인 조건에는 영향을 주지 않는다.
