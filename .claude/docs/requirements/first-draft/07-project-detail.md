# 7. 실적 상세 화면 요구사항

> 이하 `실적 상세 화면` 요구사항에서 2열로 구성된 **프로젝트 이미지 + 프로젝트 소개 영역 전체를 `본문`이라고 지칭한다.**

## 7.1 프로젝트 제목

실적 상세 화면의 제목은 실적 리스트에서 선택한 **프로젝트 이름**으로 설정한다.

프로젝트 이름 아래에 존재하는 `회사 대표 선`은 제거한다.

현재 Demo Project임을 알리는 문구는 삭제한다.

위 두 요소가 제거된 이후:

- 프로젝트 제목
- 본문

사이의 과도한 Vertical Gap을 줄인다.

---

## 7.2 실적 현황 목록 버튼

현재 `본문` 1열 이미지 위에 겹쳐서 표시되고 있는 `실적 현황 목록` 버튼은 해당 위치에서 제거한다.

버튼을 프로젝트 제목과 동일한 행으로 이동한다.

Desktop 기준:

- 왼쪽 → 프로젝트 이름
- 오른쪽 → 실적 현황 목록 버튼

으로 양끝 정렬한다.

실적 현황 목록 버튼은:

- 배경 제거
- 테두리 제거

상태로 구성한다.

Hover 시:

- 버튼 하단에 네이비 색상의 Underline이 나타난다.
- Underline은 **왼쪽에서 오른쪽으로 길이가 증가하는 Animation**으로 표시한다.
- Hover가 종료되면 반대 방향으로 자연스럽게 사라지도록 한다.

실적 현황 목록 버튼을 클릭하면 **메인 페이지의 실적 현황 섹션으로 이동한다.**

다른 페이지에 있는 상태이므로 메인 페이지 이동 후 실적 현황 섹션 위치로 정상적으로 Scroll 되어야 한다.

---

## 7.3 본문

- 본문 2열 내부에 존재하는 `회사 대표 선`은 삭제한다.
- 본문 2열 내부의 `PROJECT INFO` 글자 색상을 네이비로 변경한다.

프로젝트 이미지를 단건 저장에서 다건 저장으로 변경함에 따라 이미지 표현 방식을 다음과 같이 수정한다.

- 현재 레이아웃은 유지하되 이미지가 캐로셀로 보여지게 한다.
- 이미지 목록을 캐로셀 이미지의 하단에 필름 처럼 보여지게 한다.
- 케로셀의 양끝 가운데에 `<`, `>`를 위치시킨다. 꺽쇠의 디자인은 배경없이 테두리 선 없이 꺽쇠만 표시한다.
- 이미지는 계속해서 순환한다.
- 3초 간격으로 자동으로 이동한다.
