# 9. Footer 요구사항

Footer의 기존 전체적인 구성과 디자인은 유지한다.

기존 Footer 정보에 다음 정보를 추가한다.

- 대표 `{대표이름}`
- 사업자등록번호 {번호는 임시로 기입}

대표전화와 이메일은 동일한 한 줄에 이어서 표시하지 않고 **줄바꿈하여 각각 구분해서 표시한다.**

Footer에는 최종적으로 회사의 기본 기업정보를 확인할 수 있도록 구성하되, Contact와 일부 정보가 중복되는 것은 허용한다.

Contact는 연락 및 방문 목적의 영역으로 사용하고 Footer는 회사 기본 정보를 확인하는 영역으로 사용한다.

Footer Typography는 전역 Typography 요구사항에 따라 일반 본문보다 작은 **13~14px 수준**을 기본으로 하며 가독성을 유지한다.
