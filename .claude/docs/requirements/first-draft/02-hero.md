# 2. Hero 요구사항

- Hero 영역은 헤더와 **2px 간격**을 두고 배치한다.
- Hero 이미지에는 기존에 적용되어 있는 Gradient Overlay를 제거한다.
- 이미지는 색상이나 밝기를 변경하는 Gradient 없이 **이미지 원본이 그대로 보이도록 한다.**
- 현재 Hero에 사용되는 문구 내용은 변경하지 않는다.

기존 하단에 표시되는 다음 항목은 제거한다.

- 산업 자동화
- 빌딩 자동화
- 데이터센터 자동화

제거한 해당 위치에는 다음 두 CTA를 배치한다.

- 사업영역 보기
- 프로젝트 문의

두 CTA는 기존 Hero의 전체적인 디자인 스타일을 해치지 않는 범위에서 클릭 가능한 버튼 또는 링크 형태로 구성한다.

Hero에 여러 장의 이미지가 사용되는 경우:

- 이미지 정지 버튼 제거
- 이미지 시작 버튼 제거
- 별도의 사용자 조작 없이 이미지가 자동으로 순환
- 마지막 이미지 이후 첫 이미지로 다시 돌아오는 **무한 반복 방식**으로 구현
