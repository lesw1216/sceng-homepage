# 8. Contact 부분 요구사항

> 이하 `Contact` 요구사항에서는 Contact 영역을 `컨택`이라고 지칭한다.

- 컨택 제목 아래의 기존 안내 문구는 삭제한다.
- 기존 2열 본문 중 기존 주소 정보를 표시하고 있는 **2열 주소 영역은 삭제한다.**

- 컨택 내부는 다음 두 개의 Sub Section으로 구성한다.
  1. 프로젝트 문의
  2. 오시는 길

- 두 Sub Section은 각각 독립된 제목과 내용을 가지되 하나의 Contact 영역 안에서 일관된 Typography와 간격을 사용한다.

---

## 8.1 프로젝트 문의

프로젝트 문의 제목 아래에 다음 안내 문구를 표시한다.

`프로젝트 및 시스템 구축에 관한 문의사항이 있으시면 언제든지 연락 주시기 바랍니다.`

현재 컨택에 존재하는 회사 정보 UI의 기본적인 틀은 유지한다.

단, 다음 사항을 수정한다.

### 왼쪽 컬럼

기존 오렌지색을 제거하고 **옅은 회색**으로 변경한다.

### 삭제 항목

다음 정보는 프로젝트 문의 영역에서 삭제한다.

- 휴대전화
- 홈페이지
- 주소

### Typography

기존 회사 정보 영역보다 **글자 크기를 증가**시킨다.

단순히 특정 값을 임의 지정하기보다 전역 Typography Scale을 기준으로 기존 단계보다 한 단계 큰 Scale을 사용한다.

## 8.2. 오시는 길

오시는 길 제목 아래에 다음 형태로 회사 주소를 표시한다.

`본사: {회사주소}`

회사 주소 아래에는 **지도 API를 이용한 지도 영역을 추가할 예정**이다.

구현 가능한 경우 현재 작업에서 지도 API를 이용하여 지도 표시까지 구현한다.

지도 API Key 또는 외부 서비스 설정이 필요한 등의 이유로 즉시 구현하기 어려운 경우:

- 지도 영역이 들어갈 레이아웃 공간을 먼저 확보한다.
- 향후 지도 Component를 삽입하기 쉽게 독립된 영역 또는 Component로 구성한다.
- 지도 미구현 때문에 오시는 길 전체 Layout이 깨지지 않도록 한다.

지도 아래 또는 인접한 위치에:

`네이버 지도에서 보기`

버튼을 추가한다.

해당 버튼은 회사 위치를 네이버 지도에서 확인할 수 있도록 연결한다.

버튼에는 클릭 가능 요소에 대한 전역 Pointer Cursor 규칙을 적용한다.
