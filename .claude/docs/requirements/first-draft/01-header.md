# 1. 헤더 요구사항

## 1.1 헤더 회사 로고

- 회사 로고를 클릭하면 **메인 페이지의 최상단으로 이동해야 한다.**
- 현재 사용자가 어느 페이지 또는 어느 섹션에 위치해 있는지와 관계없이 왼쪽 회사 로고는 항상 클릭 가능해야 한다.
- 스크롤을 이용하여 수동으로 다른 섹션으로 이동한 경우에도 동일하게 동작해야 한다.
- 다른 페이지에서 회사 로고를 클릭한 경우에도 메인 페이지로 이동한 후 최상단이 표시되어야 한다.
- 로고는 /public/sce-log-ko.svg를 사용한다.
- ~~로고의 크기는 비율을 유지하며 `height`를 15px로 설정하고 로고의 비율을 유지한다.~~
- 로고의 크기를 현재보다 한 단계 줄인다.

## 1.2 헤더 네비게이션

- 헤더의 각 네비게이션 메뉴를 클릭하면 해당 메뉴에 대응하는 섹션으로 이동한다.
- 메인 페이지 내부 섹션을 대상으로 하는 메뉴는 해당 섹션 위치로 정확하게 Scroll 이동한다.
- 현재 활성화된 메뉴는 사용자가 클릭하여 이동한 경우뿐만 아니라 **스크롤을 통해 해당 섹션에 진입한 경우에도 현재 위치를 정상적으로 반영**해야 한다.
- 헤더의 높이를 줄이면서 섹션 위치로 이동 시 정확하게 Scroll 이동되지 않음. 해당 부분을 정확하게 이동하도록 수정한다.

색상은 다음과 같이 지정한다.

- 비활성화 Navigation: **네이비**
- 활성화 Navigation: **오렌지**
- 활성화 Underline: **오렌지**

Hover 시:

- 버튼 하단에 네이비 색상의 Underline이 나타난다.
- Underline은 **왼쪽에서 오른쪽으로 길이가 증가하는 Animation**으로 표시한다.
- Hover가 종료되면 반대 방향으로 자연스럽게 사라지도록 한다.

- 글씨의 크기를 현재 크기보다 한단계 키운다.

## 1.3 헤더 식별

- `회사 대표 선`으로 구성된 헤더 하단 테두리를 일반적인 회색 수평선으로 수정한다.
- 뚜련한 경게선을 회색으로 구성하였으므로, 배경 등을 본문과 헤더를 구분지을 수 있도록 수정한다.

## 1.3 헤더 네비게이션 버그

- 사업 실적 상세 페이지 이동 시 네이게이션의 활성화가 풀리지 않도록 수정한다.
- 사업 실적 상세 페이지에서 메인 페이지로 이동 시 네비게이션의 활성화가 동작하지 않는 버그를 해결한다.

## 수정 오류

- 현재 기존에 작동되던 네비게이션 헤더 활성화가 작동하지 않음 수정 바람.
