# 1. 헤더 요구사항

## 1.1 헤더 회사 로고

- 회사 로고를 클릭하면 **메인 페이지의 최상단으로 이동해야 한다.**
- 현재 사용자가 어느 페이지 또는 어느 섹션에 위치해 있는지와 관계없이 왼쪽 회사 로고는 항상 클릭 가능해야 한다.
- 스크롤을 이용하여 수동으로 다른 섹션으로 이동한 경우에도 동일하게 동작해야 한다.
- 다른 페이지에서 회사 로고를 클릭한 경우에도 메인 페이지로 이동한 후 최상단이 표시되어야 한다.
- 로고는 /public/sce-log-ko.svg를 사용한다.
- 로고의 크기는 비율을 유지하며 헤더의 하단 테두리와 2px 차이가 나도록 크기를 키운다.

---

## 1.2 헤더 네비게이션

- 헤더의 각 네비게이션 메뉴를 클릭하면 해당 메뉴에 대응하는 섹션으로 이동한다.
- 메인 페이지 내부 섹션을 대상으로 하는 메뉴는 해당 섹션 위치로 정확하게 Scroll 이동한다.
- 현재 활성화된 메뉴는 사용자가 클릭하여 이동한 경우뿐만 아니라 **스크롤을 통해 해당 섹션에 진입한 경우에도 현재 위치를 정상적으로 반영**해야 한다.

색상은 다음과 같이 지정한다.

- 비활성화 Navigation: **네이비**
- 활성화 Navigation: **오렌지**

현재 활성화된 헤더 Navigation 아래에 표시되는 `회사의 대표 선`은 제거한다.

즉, 활성 상태는 **텍스트 색상 변화만으로 표현**한다.
