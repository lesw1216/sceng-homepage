# 3. 회사 소개 요구사항

현재 회사 개요/주요 생산품목 영역과 핵심 가치 영역은 2열 Grid Layout으로 배치되어 있다.

이를 **단일 컬럼(1열) 레이아웃​**으로 변경한다.

각 섹션은 컨테이너의 전체 너비를 사용한다.

전체 배치 순서는 다음과 같다.

1. 회사 개요
2. 핵심 가치
3. 주요 생산 품목
4. 주요 생산품목

---

## 3.1 회사 소개

- 현재 2개의 열로 구성되어 있는 회사 소개의 **왼쪽 열을 완전히 제거한다.**
- 기존 오른쪽 열을 전체 너비를 사용하는 하나의 본문으로 구성한다.

현재 문구:

`미래를 제어하는 기술,\n신뢰를 이어가는 기업`

수정 문구:

`미래를 제어하는 기술, 신뢰를 이어가는 기업`

- 위 문구는 한 줄로 표시한다.
- 회사 소개 내용에서 `에스씨엔지니어링 대표 이구호입니다.` 문구는 삭제한다.

회사 소개 본문의 우하단에 다음 문구를 추가한다.

- `에스씨엔지니어링 주식회사 임직원 일동`

해당 문구는 다음과 같은 조건으로 구성한다.

- 일반 본문보다 한 단계 큰 글씨
- Bold
- 본문의 서명 또는 마무리 문구처럼 보이도록 우측 정렬

---

## 3.2 회사 개요

회사 개요의 다음 Label 글자 색상은 **네이비**로 변경한다.

- 회사명
- 대표이사
- 주요사업

회사명은 한글명과 영문명을 함께 표기한다.

표기 문구:

`에스씨엔지니어링(주) | SC ENGINEERING Co., Ltd`

---

## 3.3 핵심 가치

다음 두 핵심 가치는 서로 나란히 배치한다.

- `Smart Solution`
- `Control & Trust`

Desktop에서는:

- Smart Solution → 1열
- Control & Trust → 2열

형태로 한 행에 배치한다.

각 핵심 가치 박스의 테두리 중 **상단 테두리를 `회사의 대표 선`으로 변경한다.**

두 Box는 높이, 여백, 제목 위치 및 내부 요소의 정렬 기준을 통일한다.

---

## 3.4 주요 생산품목

- 현재 주요 생산품목 제목 왼쪽에 존재하는 **수직 오렌지 선을 제거한다.**

- 주요 생산품목 제목의 Heading Level 및 시각적 크기를 다음 단락과 동일한 수준으로 변경한다.
  - 회사 개요
  - 핵심 가치

- 주요 생산품목의 각 Item Box 배경색은 기존 전체 페이지 배경색과 동일하게 변경한다.
- 현재 전역 배경이 흰색인 경우 각 Item Box 역시 흰색 계열을 사용하여 배경으로 과도하게 구분하지 않는다.
