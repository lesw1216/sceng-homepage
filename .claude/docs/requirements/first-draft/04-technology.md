# 7. 보유 기술 요구사항

보유기술 제목 아래 소개 문구는 다음 한 문장으로 수정하고 한 줄로 표시한다.

`분석·설계부터 개발·제작, 설치·시운전·교육까지 하나의 흐름으로 책임지고 종합적인 서비스를 제공합니다.`

- 기존 각 3개 단락에 존재하는 Stepper UI를 제거한다.
- 각 단락 제목을 별개의 Stepper 영역에 두지 않고 **단락 Box 내부에 통합한다.**
- 각 단락의 기존 제목 내용 자체는 변경하지 않는다.
- 기존 주황색 정사각형 배경의 번호 디자인은 회사 소개의 `핵심 가치` 각 박스에 적용된 번호 디자인과 동일한 형태로 변경한다. 단, 색상은 **네이비**로 수정한다.

- 각 보유기술 단락 Box의 상단 테두리는 `회사의 대표 선`으로 변경한다.

3개의 Box는:

- 상단선 위치
- 번호 위치
- 제목 위치
- 내부 Padding
- 제목과 본문 간격

을 동일하게 유지한다.
