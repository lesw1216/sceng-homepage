## 실적 현황

현재 수기로 실제 실적을 입력하였음. 해당 내용을 첨부한 파일을 참고하여 재수정 필요.

- 이미지의 비율이 실적 현황 상세에서 맞지 않음. 우리가 명시한 이미지 규격에 맞게 사진을 수정하거나 변경해서 등록 바람.
- 가톨릭대학교 실적은 세부 프로젝트가 2개로 구분되어있음. 해당 부분을 하나로 합쳐주고, 상세 설명에서 내가 올린 실적 이미지를 참고하여 작성.
- 엘리시안 강촌 실적은 세부 프로젝트가 2개로 구분되어있음. 해당 부분을 하나로 합쳐주고, 상세 설명에서 내가 올린 실적이미지를 참고하여 작성.

---

- 실적 현황 리스트에서 고객 ~ 위치의 분류 이름 색상이 눈에 띄지 않음, `네이비`, 볼드체로 변경.

---

- 카드의 아이템 목록이 줄바꿈이 되지 않게 수정, 조건은 카드의 너비가 변경되지 않아야함, 즉 줄바꿈은 되지않되 각 카드의 너비는 동일해야하고 5열 2행의 카드 구조도 유지해야함.

---

내부 코드를 살펴본 결과. 현재 실적 현황의 상세 탭을 실적의 카테고리를 라이브로 받아 보여주고 있음
데이터센터 실적이 없으면 데이터센터 실적이 보이지 않는다는 문제가 발생하는 것.
즉, 데이터 센터 실적이 없어도, 실적이 없음을 보여줘야한다는 것임.

따라서 상세 탭은 다음과 같이 코드 구조를 수정해야함.

- 추후 서버 확장 시 서버에서 Enum 데이터를 받아 보여줄 예정이므로 현재 프론트 코드단에서도 상세탭을 별도의 enum 스타일로 분리시켜 사용.
- 각 실적의 카테고리는 위에 선언하는 상세탭의 enum 값을 사용하여 저장함.

- 발주사를 제거한다.\

3건의 실적의 고객사는 다음과 같이 수정한다.

- 배건하이텍 -> 포스에이텍
- 서울성모병원 -> SJ 전기
- 강촌 엘리시안 -> BSTGroup
